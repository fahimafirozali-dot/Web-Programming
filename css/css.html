CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the visual presentation, layout, and formatting of web documents, most commonly those written in HTML or XML.

CSS is a cornerstone technology of the World Wide Web. While HTML provides the structural foundation of a page, CSS applies the styling—such as colors, fonts, spacing, positioning, and responsive layouts.
